# 楚河汉界 · 中国象棋

> 一款面向中国象棋爱好者与初学者的浏览器象棋应用，通过标准棋盘、完整规则校验、自然化人机对弈和清晰的将军/胜负提示，让用户无需安装客户端即可快速完成本地双人或人机对局。

## 1. 项目简介与产品定位

“楚河汉界”是一款中国风网页象棋游戏，主要服务于想随时练棋的初学者、希望和身边朋友同屏切磋的玩家，以及需要了解网页游戏开发流程的学习者。

产品解决的核心问题是：传统象棋软件通常需要下载安装，部分网页棋盘不规范、规则提示不清晰，人机走法又容易显得机械。本项目将标准 9×10 象棋棋盘、完整行棋约束、分级 AI、将军与胜负页面、背景音乐和本地登录体验整合到一个响应式网页中，打开链接即可使用。

### 已实现功能（本次 MVP）

- 中国风登录页，支持账号昵称进入、游客试玩和登录状态记忆。
- 登录成功后展示“棋局已备”过渡页，并自动进入模式大厅。
- 大厅模式选择：本地双人、人机对弈；在线匹配作为后续入口展示。
- 标准 9 路 10 行棋盘、楚河汉界、九宫斜线与完整棋子初始布局。
- 车、马、相/象、仕/士、帅/将、炮、兵/卒的基础行棋规则。
- 自动阻止送将、将帅照面等非法走法，并判断将军、将死和胜负。
- 人机对弈提供“入门 / 进阶 / 挑战”三档难度。
- AI 采用局面评估、Alpha-Beta 搜索、开局方案和近优解随机选择，减少固定走法。
- 悔棋、重新开始、走棋记录、AI 思考状态。
- 将军提示页带自动倒计时，不会阻塞后续回合；胜负结算页支持再来一局或返回大厅。
- 背景音乐开关及偏好记忆，页面切换带过渡动画。
- 响应式布局，兼容常见电脑和移动端浏览器。

### 后续迭代

- 正式账号系统、云端棋谱和战绩排行。

## 3. 启动方式与环境变量

### 环境要求

- Node.js 22.13.0 或更高版本
- npm（随 Node.js 安装）
- Chrome、Edge、Firefox 或 Safari 等现代浏览器

### 本地开发

```bash
npm install
npm run dev
```

启动后，在浏览器访问终端显示的本地地址，通常为 `http://localhost:3000/`。

### 构建生产版本

```bash
npm run build
```

### 单文件离线版本

仓库根目录的 `楚河汉界-单文件提交版.html` 已内嵌 HTML、CSS 和 JavaScript，可直接双击运行，无需安装依赖或联网。

### 环境变量

当前 MVP 不依赖第三方接口、数据库或密钥，因此无需配置 `.env`。登录信息、音乐偏好只保存在当前浏览器的 `localStorage` 中，不会上传服务器。

## 4. 核心使用流程

1. **进入应用**：打开在线链接或双击单文件 HTML。
2. **登录/试玩**：输入用户名和密码后进入，或选择“游客试玩”；当前原型以本地体验为主，不校验真实账号。
3. **登录过渡**：登录成功后展示欢迎过渡页，约 1.9 秒后自动进入大厅，也可点击按钮立即进入。
4. **选择模式**：在大厅选择“本地双人”，或在人机模式中选择入门、进阶、挑战难度。
5. **开始对局**：红方先行。点击己方棋子后，可走位置会被标记；再点击目标交叉点完成落子。
6. **查看状态**：右侧面板显示当前回合、走棋记录和 AI 思考状态；可随时开关音乐。
7. **辅助操作**：点击“悔棋”撤回最近回合，点击“重新开始”恢复初始棋局。
8. **将军与结算**：出现将军时展示专门提醒页，倒计时结束后自动返回并继续回合；形成将死或无合法应对时进入胜负页，可再来一局或返回大厅。

## 5. AI 介入环节说明

AI 主要介入人机对弈中的黑方决策，流程如下：

1. 用户执红完成合法落子后，系统生成黑方全部合法候选走法。
2. 开局阶段从多套符合象棋思路的出子方案中选择，避免每局完全相同。
3. 中后盘使用棋子价值、位置、将军压力等局面指标进行评分。
4. 进阶和挑战难度使用 Minimax 与 Alpha-Beta 剪枝搜索后续局面；难度越高，搜索深度和候选质量越高。
5. 系统在评分接近的优秀走法中按权重随机选择，并对短期重复移动进行惩罚，使表现更接近自然玩家。
6. 每次 AI 落子仍经过同一套规则校验，保证不会走出送将、越界或违反棋子规则的着法。

当前 AI 完全在浏览器本地运行，不调用云端大模型或外部 API，因此响应快、可离线使用，也不会产生接口费用。

| 分类 | 技术 | 用途 |

| 前端框架 | React 19 + TypeScript 5 | 页面组件、状态管理和类型约束 |

## 8. 数据与隐私说明

- 本项目不收集真实姓名、手机号或支付信息。
- 原型登录仅用于展示产品流程，账号数据不上传服务器。
- 游戏和 AI 均在浏览器内运行。
- 清除浏览器站点数据即可删除本地保存的用户名与音乐偏好。

## 9. 已知限制

- 当前登录为本地模拟，不提供真实注册、找回密码和多端同步。
- 在线匹配尚未开放。
- AI 适用于 MVP 演示和日常练习，尚未达到专业象棋引擎强度。
